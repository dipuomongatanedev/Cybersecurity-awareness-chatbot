Cybersecurity Awareness Chatbot

Overview

The Cybersecurity Awareness Chatbot is a C# console application developed as part of my Software Development coursework.

The project aims to educate users about cybersecurity awareness by providing information on common online threats and safe digital practices.

Features

The chatbot covers the following cybersecurity topics:

* Password Safety: Understanding the importance of creating and maintaining secure passwords.
* Phishing Attacks: Learning about phishing and how to recognise suspicious messages and links.
* Safe Browsing: Understanding safer browsing habits and ways to reduce online risks.
* Cybersecurity Best Practices: Exploring general practices that help users protect themselves online.

Technologies Used

* C#
* .NET
* Visual Studio

Purpose of the Project

This project allowed me to practise C# programming while exploring how software can be used to promote cybersecurity awareness and help users make safer decisions online.

It forms part of my learning journey as a Software Development student.
